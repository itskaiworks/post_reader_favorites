# Post Reader & Favorites

A Flutter-based application developed as part of Finals Laboratory Examination 2. It demonstrates post retrieval, content display, and favorites management using Flutter and Dart.

## Live Demo

Explore the deployed application:

**[Post Reader & Favorites – Live Website](https://itskaiworks.github.io/post_reader_favorites/)**

## Overview

Post Reader & Favorites is a Flutter application focused on displaying post content and providing a way to manage favorite posts in one place.

The project demonstrates the use of Flutter and Dart in developing applications that work with structured data, present dynamic content, and support user interactions.

## Features

- **Post Display** – Presents available posts in an organized interface.
- **Post Details** – Provides a way to view individual post content.
- **Favorites Management** – Allows users to save and access favorite posts.
- **Interactive Interface** – Uses Flutter widgets to support user interactions.
- **Web Deployment** – Accessible through a live website hosted on GitHub Pages.

## Technologies Used

- **Flutter** – Application development framework
- **Dart** – Primary programming language
- **Material Design** – UI components and design elements
- **Git & GitHub** – Version control and source code hosting
- **GitHub Pages** – Web deployment
